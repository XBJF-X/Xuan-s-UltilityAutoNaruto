# 产品/业务背景

## 产品定位
火影忍者手游的自动化日常工具,基于图像识别与调度器自动完成每日/每周/每月/周期/活动任务。

## 用户群
火影忍者手游玩家,需要自动化完成重复性日常任务。

## 技术迁移背景
原项目基于纯 Python（PyQt5）+ `.ui` 文件构建桌面 GUI。当前正在迁移为:
- 前端:Vue3（Vite + TypeScript）+ Element Plus 等
- 后端:Python（FastAPI 等）

## 迁移目标
- 保持原有功能完整,同时提供现代化的 Web 界面
- 助手设置（键位配置、串口选择、控制模式、截图模式等）
- 全局设置反映 `setting.ini` 内容
